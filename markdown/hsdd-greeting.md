# A Note to Fellow Engineers

> Source: `hsddGreeting.pdf` — no Mathcad worksheet; this is a cover letter.
> From the Mathcad 13.1 companion files to *High-Speed Digital Design:
> A Handbook of Black Magic* (Howard Johnson & Martin Graham).

January 3, 2008

To my fellow engineers:

Your interest in High-Speed Digital Design is much appreciated. The MathCad
files in this directory were created using MathCad version 13.1. If you use
the book or these files to particular advantage, please write to tell me
about it. I am always delighted to learn about new, creative uses of the
principles of signal integrity.

Thanks again for you interest, and I look forward to hearing from you.
